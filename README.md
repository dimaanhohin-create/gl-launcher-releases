## Features

- **Any version, any loader.** Vanilla, Fabric, Quilt, Forge and NeoForge, including snapshots and old versions. Fabric API / Quilted Fabric API is installed for you.
- **Java is handled for you.** The right Java version for each Minecraft version is downloaded automatically from Mojang.
- **Mods from Modrinth and CurseForge.** Mods, resource packs, shaders and modpacks in one catalog. Dependencies are installed automatically; shaders bring Iris (or Oculus on Forge).
- **Modpacks.** Install from the catalog or import a `.mrpack` / CurseForge `.zip` file — it becomes a new instance with the right loader.
- **Manage what's installed.** Enable, disable or remove files, check for updates, update a single mod or roll it back to any compatible version. Mods you drop into the folder yourself are recognised.
- **Instances your way.** Copy an instance (choose what to copy: worlds, mods, configs, screenshots…), drag cards to reorder, right-click for quick actions, double-click to play, pick a pixel-art icon.
- **Accounts.** Sign in with Microsoft, or play offline with a nickname (with your own skin via CustomSkinLoader).
- **Game log and crash help.** A separate log window with search, plus a crash window that explains the likely cause in plain words — missing mod, wrong version, out of memory and more.
- **Looks.** Night and day themes, 10 color presets plus your own colors and saved presets, a background gallery with your own images.
- **Auto-updates** in the background, no installer wizard.
- **English and Ukrainian.**

## Install

1. Download [`GLLauncher-Setup.exe`](https://github.com/dimaanhohin-create/gl-launcher-releases/releases/latest/download/GLLauncher-Setup.exe).
2. Run it, pick a language and the install folder.
3. If Windows SmartScreen shows “Windows protected your PC”, click **More info → Run anyway**. The installer isn't code-signed yet, which is why Windows warns about it.

Requirements: Windows 10 or 11 (64-bit). Nothing else — Java is installed automatically.

Your instances, worlds and settings live in `%APPDATA%\gl-launcher` and are kept when you update or uninstall the launcher.

## FAQ

**Do I need to own Minecraft?**
To play on official servers (online-mode) and with your real skin, sign in with a Microsoft account that owns Minecraft: Java Edition. Don't have it yet? [Buy Minecraft](https://www.minecraft.net/store/minecraft-java-bedrock-edition-pc).

**Where do I put my own mods?**
Right-click an instance → *Open folder*, then put the `.jar` files into `mods`. The launcher recognises them via Modrinth and CurseForge.

**The game crashed. What now?**
A crash window opens with the likely cause and buttons to copy the log or open the crash report. Send the copied text to whoever helps you with the instance.

## Встановлення

1. Завантажте [`GLLauncher-Setup.exe`](https://github.com/dimaanhohin-create/gl-launcher-releases/releases/latest/download/GLLauncher-Setup.exe).

Збірки, світи й налаштування лежать у `%APPDATA%\gl-launcher` і зберігаються при оновленні чи видаленні лаунчера.

## Питання

**Чи потрібна ліцензія Minecraft?**
Щоб грати на офіційних серверах (online-mode) і зі своїм скіном, увійдіть акаунтом Microsoft, на якому куплено Minecraft: Java Edition. Ще немає гри? [Купити Minecraft](https://www.minecraft.net/store/minecraft-java-bedrock-edition-pc).

**Куди класти свої моди?**
ПКМ по збірці → «Відкрити папку», далі `.jar`-файли — у папку `mods`. Лаунчер сам розпізнає їх через Modrinth і CurseForge.

**Гра вилетіла. Що робити?**
Відкриється вікно з імовірною причиною і кнопками «Скопіювати все» та «Відкрити звіт». Надішліть скопійований текст тому, хто допомагає зі збіркою.
